# Menu terminal SSH — retrait du TUI

Le TUI Textual (GrokNight) est retiré. `grok-forge` est un script bash :
numéros, Entrée, affichage sur `/dev/tty`, pas d’écran alternatif, pas de souris.

`forge_tui.py` reste un shim de 5 lignes pour les anciens wrappers
`~/.local/bin/grok-forge` qui l’appelaient encore.

Plus de venv textual, plus de WorkerError, plus de fuites SGR.
